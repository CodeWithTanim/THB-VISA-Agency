## 📌 Executive Overview

**THB VISA SERVICES LTD.** is recognized as one of the most reliable, dependable, and trusted visa processing and immigration consultancy agencies in Bangladesh. Located at Shyamoli Square, Dhaka, THB VISA delivers comprehensive, ethical, and high-standard visa documentation services for students, tourists, corporate business delegates, medical patients, and skilled workforce professionals.

## 🛠️ Technical Stack & Architecture

- **Markup:** Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) with ARIA labels and accessibility compliance.
- **Styles:** Custom Vanilla CSS3 with CSS Custom Properties (Design System tokens), Glassmorphic backdrop filters, CSS Grid, and Flexbox layouts. Zero external UI framework bloat.
- **Interactions:** Modern Vanilla JavaScript (ES6+):
  - Sticky header with dynamic backdrop shadow upon scroll.
  - Mobile hamburger drawer navigation with screen body-scroll locking.
  - Active navigation link highlighting synchronized with viewport scroll.
  - Intersection Observer API for smooth progressive element reveal animations (`animate-in`).
  - Native smooth scrolling with offset awareness for fixed headers.
- **Typography & Icons:** Google Fonts (`Inter` & `Poppins`), Font Awesome 6.4.0 vector icons.
- **SEO & Schema Integration:**
  - LocalBusiness Schema (JSON-LD) with geo-coordinates (`23.7746° N, 90.3655° E`), address locality, contact lines, aggregate rating (4.9 / 18 reviews), and opening hours.
  - OpenGraph (OG) and Twitter Card tags for dynamic social preview card rendering.

## 💻 Local Preview & Setup

To view and test this website locally on your computer:

### Option 1: Live Server (VS Code Extension)
1. Open the project folder in VS Code.
2. Right click on `index.html` and select **"Open with Live Server"**.

### Option 2: Python Simple HTTP Server
Open your terminal in the project directory and run:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### Option 3: Node.js (npx serve)
```bash
npx serve .
```
